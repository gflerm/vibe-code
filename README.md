# Vibe Code Projects

A collection of embedded development projects and experiments.

## Projects

### [MeshCore Cardputer ADV](MeshCore-Cardputer-ADV/)

Enhanced MeshCore mesh-networking firmware and TFT interface for the M5Stack
Cardputer ADV with the Cap LoRa-1262 module.

### [ESP32 Blink — ESP-IDF](esp32-blink-espressif/)

A PlatformIO ESP-IDF example that blinks an ESP32 RGB LED on GPIO 48 at a
configurable interval.

### [ESP32 Blink — Arduino](esp32-blink/)

A compact PlatformIO Arduino example for blinking an ESP32 RGB LED, with
configurable LED pin and timing settings.

### [M5Stack Fire Band Conditions](m5-fire-bandconditions/)

A Wi-Fi-connected amateur-radio dashboard showing local time, HF propagation
conditions, Maidenhead-based location data, diagnostics, and power saving.
